# Graphics-only assets

Place approved, versioned visual assets here, for example:

- `logo/` — application and section logos
- `icons/` — toolbar and module icons
- `backgrounds/` — approved backgrounds
- `themes/` — static theme resources

Do not place executable code, installers, database files, user records, credentials, or operational documents here.

## Compatibility
Graphics updates must not alter menu structure, labels, layout, permissions, workflows, or application logic. Keep existing bundled assets as the offline fallback. Use stable filenames only when compatibility is guaranteed; otherwise use versioned paths and update the manifest.

No production assets are published in this starter repository.
